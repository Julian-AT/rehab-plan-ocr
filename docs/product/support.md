# Support guide

The interface remains German. If an appointment is missing, check selected
calendars, calendar permission and the selected day before refreshing. Refresh
reads local events; it does not repeat an uncertain write. Use the confirmed repair
flow for unresolved calendar operations.

For an incorrectly recognized plan, use a sharp, complete image with visible table
edges. Review all critical fields and correct them before confirming import.
Synthetic test performance does not guarantee accuracy on a particular photo.

For voice problems, check microphone/speech permission and installed German speech
assets. Initial asset preparation may need Internet. Verify output volume and the
selected installed voice. The default app uses Apple system speech; Victoria is
available only in the separately configured personal profile.

If saving succeeds but reminder maintenance reports a problem, inspect the saved
event and notification settings instead of repeating the write. Calendar alarms
remain a fallback when scheduling completion is uncertain.

Before erasing data or updating a device, preserve the required backup. Device
updates must retain the application identity and proceed without uninstalling.
Only sanitized diagnostics should accompany a support request; do not attach
private plan images or transcripts unintentionally.
